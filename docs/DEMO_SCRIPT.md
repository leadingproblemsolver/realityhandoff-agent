# Demo script — under 3 minutes

## 0:00–0:20 — thesis

Open the product root.

> Agents can read context and act, but the next agent often cannot prove what was known, why the action was authorized, whether it landed, or what should be trusted next. Reality Handoff turns DataHub context into a proof-carrying execution protocol.

Point to:

`Evidence → Reality → Gate → Contract → Verify → Handoff`

## 0:20–0:55 — live context

Switch to **Live DataHub** and run the configured orders task.

Show:

- real target URN;
- MCP evidence IDs;
- schema/lineage evidence;
- structured reality snapshot.

## 0:55–1:20 — refusal

Run the revenue-definition control.

Show `NEEDS_HUMAN` and state explicitly: zero mutation.

## 1:20–2:10 — bounded action

Run the valid continuity task.

At the contract show:

- exact target;
- `update_description`;
- append-only operation;
- evidence dependencies;
- proposed text.

Click **Approve bounded action**.

Show the separate Verification panel and `VERIFIED` re-read result.

## 2:10–2:40 — continuity

Show the handoff result, then click **Start Fresh Agent**.

Explain that recovery calls the backend/DataHub persistence path and does not reuse frontend conversation state.

Show recovered execution ID/source.

## 2:40–2:58 — close

> DataHub is not just context for this agent. It becomes the shared reality and continuity substrate across agents: evidence-backed decisions, bounded actions, verified effects, and inheritable handoffs.
