# Claim boundaries

We claim only what a live run proves.

**Claimed by design/tests:** deterministic evidence gate, explicit action contract, mutation allowlist, secret redaction, exact marker verification, idempotency, durable handoff structure, replay evaluator.

**Claim only after live P0–P4:** tenant MCP reachability, actual DataHub mutation, actual DataHub `save_document` persistence, fresh-session recovery from the live tenant.

**Not claimed:** warehouse SQL execution, correctness of raw data, autonomous semantic truth resolution, arbitrary production-safe metadata editing, or immunity to all prompt injection.
