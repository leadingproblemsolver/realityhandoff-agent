# Claim boundaries

## Proven offline by this package

- deterministic evidence/reality/gate/contract logic;
- ambiguity refusal control;
- append-only action planning;
- agent mutation gate + exact target scope enforcement;
- runtime MCP schema binding;
- deterministic re-read verification logic;
- handoff persistence/recovery logic under mocked MCP responses;
- judge-facing API/frontend contract;
- fixture positive/refusal/tamper behavior;
- secret scan and browser-secret exclusion.

## Claim only after live P0–P4

- actual DataHub MCP reachability;
- actual reads against the chosen showcase asset;
- actual `update_description` write;
- actual post-write DataHub re-read;
- actual `save_document` persistence when exposed, or disclosed fallback;
- fresh-process recovery from that live DataHub instance.

## Not claimed

- warehouse query execution;
- raw-data correctness;
- autonomous resolution of ambiguous business semantics;
- arbitrary production-safe metadata editing;
- perfect prompt-injection resistance;
- durable LangGraph approval checkpoints across arbitrary server restarts (the durable product claim is the DataHub handoff after verified execution).
